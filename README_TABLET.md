# SinKa PvP 100 — Android APK

Bu proje, SinKa PvP 100 V24 mantığının Android/Kivy portudur.

## Android tablet ile APK oluşturma

1. GitHub hesabında yeni bir **public veya private repository** oluştur.
2. Bu klasördeki tüm dosyaları repository'ye yükle.
3. GitHub'da **Actions** sekmesine gir.
4. **Build SinKa PvP 100 APK** iş akışını seç.
5. **Run workflow** düğmesine bas.
6. İşlem tamamlanınca Actions çalışmasının **Artifacts** bölümündeki `SinKa-PvP-100-APK` paketini indir.
7. ZIP'i açıp `.apk` dosyasını Android tablete kur.

Bilgisayara Python veya Buildozer kurman gerekmez; derleme GitHub'ın Linux sunucusunda yapılır.

## Uygulama
- Great / Ultra / Master League
- 1–100 adet
- Shadow filtresi
- XL gerektirmeyenler filtresi
- Özel Güç (*) gerektirmeyenler filtresi
- Rank-1 IV / Lvl / CP
- Türkçe hareket adları
- Pokémon ve evrim görselleri
- XL / Özel Güç göstergeleri
- Mevcut işaretleme
- A4 profesyonel PNG pafta

Çıktılar Android'in uygulama veri klasörüne kaydedilir. İlk sürümde Android'in dosya paylaşım/SAF arayüzü ayrıca eklenebilir.
